# Analysis and handling of events

# Практическая работа
## «Анализ и обеспечение обработки исключительных ситуаций»

### Цель работы
Научиться анализировать источники исключительных ситуаций в программе, выбирать подходящие типы исключений, реализовывать их обработку, логирование и проверять поведение программы с помощью тестовых сценариев.

### Задачи
1. Проанализировать программу деления двух чисел и записи результата в файл.
2. Определить возможные исключительные ситуации.
3. Реализовать обработку исключений через `try/catch/finally`.
4. Добавить логирование ошибок в файл.
5. Проверить программу на корректных и некорректных входных данных.
6. Оформить отчёт с результатами тестирования.

### Требования к реализации
- использовать конкретные типы исключений;
- не скрывать ошибки «молча»;
- в `finally` выводить сообщение о завершении программы;
- ошибки логировать в файл `app.log`;
- результат деления записывать в `result.txt`;
- предусмотреть обработку:
  - нечислового ввода;
  - переполнения `int`;
  - деления на ноль;
  - ошибок записи в файл;
  - прочих непредвиденных ошибок.

### Анализ исключительных ситуаций

| Ситуация | Где возникает | Тип исключения | Обработка |
|---|---|---|---|
| Введено не число | `int.Parse` | `FormatException` | Сообщить пользователю, записать в лог |
| Пустой ввод | `ReadInt` | `FormatException` | Сообщить, записать в лог |
| Число больше/меньше диапазона `int` | `int.Parse` | `OverflowException` | Сообщить, записать в лог |
| Второе число равно 0 | `Divide` | `DivideByZeroException` | Явная проверка и сообщение |
| Нет прав на запись файла | `File.WriteAllText` | `UnauthorizedAccessException` | Сообщить, записать в лог |
| Каталог для файла не найден | `File.WriteAllText` | `DirectoryNotFoundException` | Сообщить, записать в лог |
| Прочие ошибки ввода-вывода | `File.WriteAllText` | `IOException` | Сообщить, записать в лог |
| Непредвиденная ошибка | Любое место | `Exception` | Перехватить последним, залогировать |
